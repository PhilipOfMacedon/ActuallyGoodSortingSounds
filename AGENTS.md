# Repository guidance

Read `agent-memory/README.md` for current project context before changing the architecture.

The owner keeps local coding and Git workflow references in:

- `.local-guidance/CODING_PRACTICES.md`
- `.local-guidance/GIT_WORKFLOW.md`

When present, read these references and apply them with the user's current instructions and this repository's established conventions. The coding reference contains an old absolute workflow path; the sibling local `GIT_WORKFLOW.md` is the supplied replacement for that path.

The entire `.local-guidance/` directory is intentionally Git-ignored. Do not force-add its contents. Its absence in a fresh checkout is expected and does not prevent ordinary repository work.
